5. COMO RODAR O PROJETO (OPCIONAL)

Não é preciso rodar nada para avaliar: os resultados já estão no relatório,
nos notebooks e nas evidências do repositório.

Para rodar o chat na sua máquina, são quatro passos (precisa do Git e do uv):

   git clone https://github.com/efraxpc/pedro_asistente_de_compras.git
   cd pedro_asistente_de_compras
   uv sync --python 3.13 --all-extras --locked
   cp .env.example .env

Depois preencha no arquivo .env as SUAS PRÓPRIAS chaves (o projeto não traz
nenhuma):

   OPENAI_API_KEY      liga o agente
                       criada em https://platform.openai.com/api-keys
   LANGSMITH_API_KEY   permite repetir a avaliação do agente
                       criada em https://smith.langchain.com

E abra o chat:

   ./project.sh start

O chat abre em http://localhost:8501

Primeiro teste sugerido: clique em
"Compare 5 unidades de PEC-01-0001 com prazo de 7 dias".
A resposta esperada é CentroPeças, R$ 7.279,83, entrega em 2 dias.

Todos os dados do projeto (catálogo, fornecedores, preços e políticas)
são fictícios.
